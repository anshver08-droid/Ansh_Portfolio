# Ansh Verma — Software Engineering Portfolio & ATS System

A production-grade, ATS-aware personal software engineering portfolio and case study platform for **Ansh Verma** (B.Tech CSE-AIML at ABES Engineering College).

Engineered with **Next.js 15 (App Router)**, **TypeScript**, and **Tailwind CSS**. Built to demonstrate rigorous backend correctness, transactional integrity, and responsible AI system architecture.

---

## 🎯 Positioning & Core Philosophy

This platform is architected around real software engineering principles rather than superficial student templates:
- **Correctness Before Complexity**: Demonstrating how database constraints and transactional commits eliminate double-booking concurrency bugs.
- **Verifiable AI Engineering**: Multi-stage verification pipelines requiring formal invariants, mutation testing, and human approval gates before AI-generated code is merged.
- **Responsible Domain Applications**: Non-diagnostic pre-consultation clinical intake assistants adhering to strict zero-fabrication policies.
- **Zero Fabrication**: Absolutely no invented metrics, unearned certifications, fake user stats, or fabricated company associations.

---

## 🛠️ Tech Stack & Architecture

- **Framework**: Next.js 15 (App Router with Server Components & Dynamic Rendering)
- **Language**: Strict TypeScript 5.8
- **Styling**: Tailwind CSS with custom dark tokens (`#080c14`, Electric Cyan, Emerald accents)
- **Icons**: Lucide React
- **Typography**: Inter (UI & Narrative) & JetBrains Mono (Systems & Code)
- **SEO & Machine Readability**:
  - Semantic HTML5 with strict WCAG AA contrast compliance
  - Schema.org JSON-LD structured data (`Person`, `WebSite`)
  - Automated `sitemap.xml` and `robots.txt`
  - Print stylesheet configured for high-fidelity 1-column ATS resume export
  - Reduced-motion accessibility support (`prefers-reduced-motion`)

## 🚀 Local Development Setup

### Prerequisites
- Node.js `v18.18+` or `v20+` (tested on Node v24)
- npm `v9+` or `v10+`

### Installation
```bash
# Clone the repository
git clone https://github.com/anshver08-droid/PortCv.git
cd PortCv

# Install dependencies
npm install

# Setup local environment file
cp .env.example .env.local

# Run the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
# Type check and generate production static artifacts
npm run build

# Start production server
npm run start
```
